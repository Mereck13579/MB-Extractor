# How to install
## Chrome
1) Download and extract the latest release
2) Go to ```chrome://extensions/```
3) Enable Developer mode (if not already enabled)
4) Click Load unpacked
5) Navigate to the extracted folder and select it

# How to use
1) Go to any Melonbooks product page
2) Pop-up appears in the top right corner
3) Click Copy to copy the data in text only format, Copy row to copy data in a spreadsheet friendly format, refresh in case the information changed on the page

You can also reduce the pop up (for instance to access the cart/login/my page links) by clicking the reduce icon on the top right corner of the pop up, doing so will shrink the extension into a convenient 🍈 icon. Click on it to make it appear again.
